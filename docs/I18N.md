# Idiomas (español / inglés)

## Modelo

- **Estilo gettext**: el texto en **español es la clave**. En el código se escribe `t('Guardar cambios')` y el catálogo inglés lo traduce. Si una traducción faltara se muestra el español (nunca una clave cruda).
- **App** (panel, admin, login, cuenta, landing): el idioma lo elige **cada usuario** (selector en la barra superior). Se guarda en la cookie `locale` y en `profiles.locale` (se aplica al iniciar sesión en otro dispositivo). Sin elección: idioma del navegador → español.
- **Sitio público y PDF generado**: el idioma lo elige **cada negocio** (*Configuración → Negocio → Idioma del sitio*, `catalogs.settings.language`), no el visitante, para que el sitio siga siendo estático y cacheable. Los textos del negocio (productos, páginas) no se traducen.
- **Garfield**: con IA responde en el idioma del usuario; el modo básico (sin IA) entiende pedidos en español.

## Cómo marcar textos

| Dónde | Cómo |
| --- | --- |
| Componente cliente de la app | `const t = useT();` (de `@/i18n/client`) y `t('Texto')` |
| Server Component / página / `generateMetadata` | `const t = await getT();` (de `@/i18n/server`) |
| Server Action | Devuelve el texto en español con `msg('…')` (lo traduce `useAction` al mostrarlo). Si el mensaje lleva datos: `const t = await getT(); return ok(x, t('Usuario @{username} creado', { username }))` |
| Mensajes de Zod, constantes, etiquetas en `lib/` | `msg('Texto')` (marca sin traducir); quien lo muestra hace `t(valor)` |
| Sitio público (`src/site-renderer`) | Cliente: `const t = useSiteT();` · Servidor: `const t = siteTranslator(site.settings.language);` |
| PDF generado (`src/features/pdf`, salvo `components/`) | `const siteT = siteTranslator(doc.site.settings.language);` y `siteT('Texto')` (ahí `t` ya son los tokens de diseño) |

Reglas:
- El primer argumento de `t()`/`msg()` debe ser un **literal** (`'…'`, `"…"` o `` `…` `` sin `${}`): así la prueba lo encuentra. Para datos usa variables: `t('Hola {name}', { name })`.
- No concatenes frases traducidas por partes: traduce la oración completa con variables.
- Fechas y números: `toLocaleString(locale)` con el idioma de `useLocale()` / `getLocale()`.
- Traducciones en `src/i18n/en/<área>.ts` (app) y `src/i18n/en/site.ts` (sitio público y PDF).

## Prueba

`tests/i18n/catalog.test.ts` extrae todos los `t('…')`, `siteT('…')` y `msg('…')` del código y falla si:
- un texto no tiene traducción,
- sobra una traducción que ya no se usa,
- una traducción pierde una variable `{…}` o está vacía.
